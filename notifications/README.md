# Proyecto de notificaciones retirado

Los correos se envían directamente desde el backend en Render con AWS SES.
No desplegar esta carpeta en Vercel ni ejecutar la antigua migración de bienvenida.
Guía actual: ../docs/contrato-correos.md.

Si existía un despliegue anterior, deshabilitarlo y retirar sus credenciales después
de comprobar el backend nuevo. No se borran tablas ni datos existentes automáticamente.
